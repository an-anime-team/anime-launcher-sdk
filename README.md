# Anime Launcher SDK

SDK based on [anime-game-core](https://github.com/an-anime-team/anime-game-core)
with some basic instruments like launcher state system and configuration file
manager.

Current implementation is considered legacy. No significant changes will be.
Please switch to [Anime Games Launcher](https://github.com/an-anime-team/anime-games-launcher)
or [sophon-tools](https://git.dawn.wine/dawn-winery/sophon-tools).
